PANDUAN PEMESANAN

File Logo yang Perlu Disiapkan Sebelum Produksi Signage

Logo asli, ukuran, warna, dan teks final membantu mencegah detail berubah saat diproduksi.

Kirim file asli bila tersedia

File vektor menyimpan bentuk sebagai jalur sehingga dapat diubah ukurannya tanpa kehilangan ketajaman seperti gambar berbasis piksel. Contohnya SVG, AI, atau EPS, tergantung isi dan cara file dibuat. PDF juga dapat berisi vektor maupun gambar raster. Nama ekstensi saja tidak memastikan seluruh isi file siap dipakai untuk produksi.

Bedakan referensi dengan berkas produksi

Foto papan, tangkapan layar, atau logo dari pesan dapat digunakan untuk diskusi awal. Namun, berkas tersebut mungkin tidak memperlihatkan detail asli saat diperbesar. Jangan sekadar mengganti nama JPG menjadi SVG. Bila logo perlu digambar ulang, lingkup pekerjaan, bentuk final, dan persetujuannya harus dibahas terlebih dahulu.

Pastikan teks dan font tidak berubah

Kirim penulisan nama secara terpisah sebagai teks yang bisa diperiksa. Untuk file desain, konfirmasikan apakah font tersedia atau tulisan sudah diubah menjadi bentuk kurva. Simpan juga versi yang masih dapat diedit untuk arsip pemilik. Jangan membagikan file font yang tidak Anda berhak distribusikan.

Berikan acuan warna dan ukuran

Warna pada layar dapat berbeda dengan material atau pencahayaan di lokasi. Sertakan acuan merek yang Anda miliki dan jelaskan bagian yang wajib dipertahankan. Jika ada beberapa versi logo, pilih satu versi untuk pesanan. Detail kecil dan garis tipis perlu diperiksa sesuai ukuran akhir, bukan hanya diperbesar secara otomatis.

Periksa desain final sebagai satu kesatuan

Sebelum persetujuan, baca ulang ejaan, susunan elemen, ukuran keseluruhan, serta posisi pada bidang. Referensi visual dan spesifikasi tertulis sebaiknya menunjuk versi yang sama. Pastikan pula Anda mempunyai hak menggunakan logo atau ornamen yang diminta untuk diproduksi.

Daftar singkat sebelum konsultasi

  • File asli dan gambar referensi
  • Teks final yang dapat disalin
  • Versi logo yang digunakan
  • Acuan warna dan ukuran akhir
